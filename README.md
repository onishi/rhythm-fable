# リズムFable 🦊🎵

リズム天国風のブラウザリズムゲーム。どうぶつたちと一緒に、流れてくるノーツをタイミングよく叩こう!

## あそびかた

1. ステージをえらんでスタート(←→ + スペースキー or クリック)
2. 「いち、に、さん、ハイ!」のカウントインのあと、右からノーツが流れてくる
3. ノーツがどうぶつのところに重なった瞬間に **スペースキー** か **タップ/クリック**!
4. 判定は3種類: **ピタッ!**(±50ms) / **まずまず**(±110ms) / **あちゃー**(ミス)
5. ⭐ の **スターノーツ** は得点2倍!
6. 最後に「ハイレベル!」「まずまず」「やりなおし…」の評価。「まずまず」以上で次のステージが解放!

## ステージ

| ステージ | キャラ | BPM | 特徴 |
| --- | --- | --- | --- |
| もりのコンサート | 🦊 | 100 | 4分打ち中心の入門ステージ |
| つきよのもちつき | 🐰 | 126 | 8分裏が混ざる中級ステージ |
| おまつりドラム | 🦝 | 140 | 高速・連打ありの上級ステージ |

ハイスコアとベスト評価はブラウザ(localStorage)に保存されます。

## 開発

```bash
npm install
npm run dev        # 開発サーバー起動
npm test           # ユニットテスト (Jest)
npm run test:coverage
npm run build      # 型チェック + 本番ビルド
npm run preview    # ビルド結果の確認
```

## 技術構成

- Vite + React 18 + TypeScript (strict)
- BGM(ドラム・ベース・メロディ)と効果音は Web Audio API でリアルタイム合成(音源ファイル不要)
- ゲームロジック(判定・スコア・譜面・伴奏生成・進行記録)は純粋関数として `src/game/` に分離し、Jest でテスト

詳細な仕様は [docs/game-design.md](docs/game-design.md) を参照。
