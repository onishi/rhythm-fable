# リズムFable 🦊🎵

リズム天国風のブラウザリズムゲーム。キツネのドラマーと一緒に、流れてくる音符をタイミングよく叩こう!

## あそびかた

1. スタートボタン(またはスペースキー)でゲーム開始
2. 「いち、に、さん、ハイ!」のカウントインのあと、右から 🎵 が流れてくる
3. 🎵 が 🦊 のところに重なった瞬間に **スペースキー** か **タップ/クリック**!
4. 判定は3種類: **ピタッ!**(±50ms) / **まずまず**(±110ms) / **あちゃー**(ミス)
5. 最後に「ハイレベル!」「まずまず」「やりなおし…」の評価が出るよ

## 開発

```bash
npm install
npm run dev        # 開発サーバー起動
npm test           # ユニットテスト (Jest)
npm run test:coverage
npm run build      # 型チェック + 本番ビルド
npm run preview    # ビルド結果の確認
```

## 技術構成

- Vite + React 18 + TypeScript (strict)
- 効果音・メトロノームは Web Audio API でリアルタイム合成(音源ファイル不要)
- ゲームロジック(判定・スコア・譜面)は純粋関数として `src/game/` に分離し、Jest でテスト

詳細な仕様は [docs/game-design.md](docs/game-design.md) を参照。
