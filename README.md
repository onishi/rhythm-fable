# リズムFable 🦊🎵

リズム天国風のブラウザリズムゲーム。どうぶつたちと一緒に、流れてくるノーツをタイミングよく叩こう!

## あそびかた

1. ステージをえらんでスタート(←→ + スペースキー or クリック)
2. 「いち、に、さん、ハイ!」のカウントインのあと、右からノーツが流れてくる
3. ノーツがどうぶつのところに重なった瞬間に **スペースキー** か **タップ/クリック**!
4. 判定は3種類: **ピタッ!**(±50ms) / **まずまず**(±110ms) / **あちゃー**(ミス)
5. ⭐ の **スターノーツ** は得点2倍! 💣 の **おじゃまノーツ** は叩いちゃダメ!
6. 10コンボで **🔥フィーバー!** 得点2倍タイム(ミスするまで継続)
7. 最後に「ハイレベル!」「まずまず」「やりなおし…」の評価。「まずまず」以上で次のステージが解放!

## ステージ

| ステージ | キャラ | BPM | 特徴 |
| --- | --- | --- | --- |
| もりのコンサート | 🦊 | 100 | 4分打ち中心の入門ステージ |
| つきよのもちつき | 🐰 | 126 | 8分裏 + 💣 が混ざる中級ステージ |
| おまつりドラム | 🦝 | 140 | 高速・連打ありの上級ステージ |
| まぼろしのオーケストラ | 🦉 | 116 | ノーツが途中で消える暗記ステージ |
| まねっこパロット | 🦜 | 108 | **コール&レスポンス**: お手本を聴いて同じリズムを返す |
| こおりのスケート | 🐧 | 112 | **逆走**: ノーツが左から右へ流れる |
| いなずまライブ | 🦁 | 132 | **とつぜん**: ノーツが直前まで見えない。音を頼りに叩く |

### 👥 みんなであそぶ (2〜4人対戦)

タイトル画面の「あそぶ にんずう」で 2〜4人を選ぶと、1台でみんなで対戦!
全員が同じ曲を自分のレーンで叩いて、スコアで勝負する。

- キー: **1P = A / 2P = F / 3P = J / 4P = ;**(タップなら自分のレーン)
- フィーバーもスターも💣も一人ずつ別判定。リザルトで 🥇🥈🥉 の順位発表
- まねっこパロットととことんライブは1人専用

### 🎪 とことんライブ (エンドレスモード)

全ステージクリアで解放。各ステージから8小節ずつランダムに繋ぎ、ラウンドごとに
どんどん速くなる(BPM 104→176)。ライフ3のサバイバルでハイスコアに挑戦!

ハイスコア・ベスト評価・パーフェクト回数はブラウザ(localStorage)に保存され、
ステージセレクトに 🏆(ハイレベル!) と ✨(パーフェクト) のメダルが並びます。
コンボをつなぐと観客のどうぶつが増えて、ビートに合わせて盛り上がります。

## 開発

```bash
npm install
npm run dev        # 開発サーバー起動
npm test           # ユニットテスト (Jest)
npm run test:coverage
npm run build      # 型チェック + 本番ビルド
npm run preview    # ビルド結果の確認
```

## 技術構成

- Vite + React 18 + TypeScript (strict)
- BGM(ドラム・ベース・メロディ)と効果音は Web Audio API でリアルタイム合成(音源ファイル不要)
- ゲームロジック(判定・スコア・譜面・伴奏生成・進行記録)は純粋関数として `src/game/` に分離し、Jest でテスト

詳細な仕様は [docs/game-design.md](docs/game-design.md) を参照。
