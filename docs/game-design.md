# リズムFable ゲーム仕様

## 概要

リズム天国風のワンボタンリズムゲーム。伴奏に合わせて右から流れてくるノーツが、キャラクターのいるヒットゾーンに重なった瞬間に入力する。

- 入力: スペースキー / タップ / クリック
- 3ステージ構成。クリアで次のステージが解放される

## 画面フロー

```
ステージセレクト → プレイ中 → リザルト
   ↑          　              │
   └──「ステージセレクト」────────┤
              ↑「もういちど!」で再プレイ
```

- ステージセレクト: ←→ で選択、スペース/Enter/クリックで開始。未解放ステージは 🔒
- リザルト: スペースキーで同じステージを再プレイ

## ステージ (`src/game/stages.ts`)

| ID | タイトル | キャラ | BPM | 小節数 | システム | 特徴 |
| --- | --- | --- | --- | --- | --- | --- |
| forest | もりのコンサート | 🦊 | 100 | 12 | flow | 4分打ち中心の入門 |
| moon | つきよのもちつき | 🐰 | 126 | 14 | flow | 8分裏(1.5拍など) + 💣 |
| festival | おまつりドラム | 🦝 | 140 | 16 | flow | 8分連打・高密度 + 💣 |
| phantom | まぼろしのオーケストラ | 🦉 | 116 | 14 | flow | ノーツが途中で消える暗記系 |
| parrot | まねっこパロット | 🦜 | 108 | 16 | echo | コール&レスポンス |

### ゲームシステム (`gameSystem`)

- **flow**(標準): ノーツが右から流れてきて、ヒットゾーンに重なった瞬間に叩く
- **echo**(コール&レスポンス): ノーツは流れない。偶数小節(コール)でお手本のリズムが
  鳴り(🎵がポップ)、次の奇数小節(レスポンス)で同じリズムを叩き返す。
  - 譜面上はレスポンス小節にだけノーツを置く(コール小節は空)
  - お手本のメロディはノーツの1小節前に鳴らす(`MelodyMode: 'callEcho'`)
  - 判定・スコアの仕組みは flow と共通
  - エンドレスの素材からは除外

各ステージは以下を持つ:

- `patterns`: 小節ごとのノーツ拍位置(0.5 = 8分裏)
- `stars`: スターノーツの拍位置(patterns の部分集合)
- `bombs`: おじゃまノーツの拍位置(patterns とは重ならない。通常ノーツから0.5拍以上離す)
- `hideNotes`: true ならノーツがヒットゾーン手前(progress 0.45→0.25)でフェードアウトする
- `music`: 伴奏設定(ベース進行 `bassRoots` とメロディ音階 `scale`、MIDIノート番号)
- `theme`: 背景・文字・アクセント色(CSSカスタムプロパティに反映)

### ノーツの種類

| 種類 | 表示 | 効果 |
| --- | --- | --- |
| normal | ステージごとの絵文字 | 通常 |
| star | ⭐🌟🎆🌠 | 基礎点2倍 |
| bomb | 💣 | 叩くと「ドカーン!」= miss扱い(コンボ消滅)。やり過ごせば何も起きない |

おじゃまノーツにはメロディ音が付かないので、音でも聞き分けられる。

## タイミング判定 (`src/game/judge.ts`)

入力時刻とノーツ時刻の差(絶対値)で判定する。

| 判定 | 表示 | 許容誤差 |
| --- | --- | --- |
| perfect | ピタッ! | ±50ms |
| good | まずまず | ±110ms |
| miss | あちゃー | ±200ms(入力あり) / 通過(入力なし) |

- ±200ms を超える入力はノーツを消費せず、空振り音だけ鳴る(ペナルティなし)
- good のときは「はやい!/おそい!」のヒントを表示する
- ノーツ時刻を 200ms 過ぎても入力がなければ自動的に miss

## スコア (`src/game/score.ts`)

- 基礎点: perfect 100点 / good 50点 / miss 0点
- **スターノーツは基礎点2倍**(コンボボーナスは倍にならない)
- **フィーバー**: コンボ10以上で突入。フィーバー中の基礎点2倍(スターと重なると4倍)。ミスで終了
- コンボボーナス: ヒットごとに現在コンボ数を加点(上限50点)
- miss でコンボは0にリセット(maxCombo は保持)
- おじゃまノーツを叩くと miss 扱い(精度も下がる)。避ければ集計対象外
- 全ノーツ「ピタッ!」なら **パーフェクト!!** 表示

### 評価(リザルト)

精度 = (perfect数 + good数 × 0.5) ÷ 総ノーツ数

| 評価 | 条件 |
| --- | --- |
| ハイレベル! | 精度 85% 以上 |
| まずまず | 精度 60% 以上 |
| やりなおし… | それ未満 |

## エンドレス「とことんライブ」 (`src/game/endless.ts`)

- **解放条件**: 全ステージを「まずまず」以上でクリア
- flow ステージから1つ選び、連続する8小節を切り出して1ラウンドにする
- ラウンドごとに BPM +8 (104 → 上限176)。ステージのテーマ・キャラ・音楽もラウンドごとに切り替わる
- ライフ3。ミス(自動ミス・叩きミス・💣)で1減り、0でゲームオーバー
- ラウンドの継ぎ目はオーディオクロック基準でシームレス(前ラウンドの終了時刻に加算)
- 譜面生成はシード付き乱数(mulberry32)で決定的
- ベストスコア/到達ラウンドを localStorage に保存(キー: `rhythm-fable-endless-v1`)

## 観客とノリゲージ

- 観客: ステージごとの3種のどうぶつ。コンボ4ごとに1匹増える(2〜6匹)。
  ビート周期(60/BPM 秒)で跳ね、フィーバー中は大ジャンプ
- ノリゲージ: 現在精度(perfect=1.0, good=0.5)をリアルタイム表示。
  色は評価と対応(金=ハイレベル圏、緑=まずまず圏、灰=やりなおし圏)

## 進行記録 (`src/game/progress.ts`)

- ステージごとに `bestScore` / `bestRank` / `playCount` / `perfectCount` を localStorage に保存(キー: `rhythm-fable-records-v1`)
- **解放条件**: 最初のステージは常に解放。以降は前のステージを「まずまず」以上でクリアすると解放
- ステージセレクトに 🏆(ベスト評価がハイレベル!) と ✨(パーフェクト達成済み) のメダルを表示
- 壊れた保存データは読み込み時に破棄する(ゲームは常に起動できる)。古い形式のデータも読み込める(perfectCount は0扱い)

## 伴奏 (`src/game/music.ts`, `src/game/audio.ts`)

譜面から伴奏イベント列を純粋関数 `buildMusicEvents()` で生成し、Web Audio API で合成する(音源ファイルなし)。

- カウントイン: クリック音のみ(いち、に、さん、ハイ!)
- ドラム: 表拍にキック/スネア交互、8分裏にハイハット
- ベース: 小節の1・3拍目にコードルート(ステージごとの進行をループ)
- メロディ: 各ノーツの拍に、ステージの音階から決定的に選んだ音 → 譜面がそのままメロディになる
- 判定音: perfect は2音チャイム(スターノーツは1オクターブ上+キラッ)、good は単音、miss は低音
- リザルト: 評価に応じたジングル

タイミングの基準はすべて `AudioContext.currentTime`(オーディオクロック)。伴奏は 150ms 先読みでスケジュールし、描画は `requestAnimationFrame` で追従する。

## エンジン (`src/hooks/useGameEngine.ts`)

- ゲーム状態(判定済み配列・スコア・伴奏の再生位置)は ref に持ち、毎フレーム `GameSnapshot` として React に反映
- ノーツは到達2拍前に出現し、ヒットゾーンまで等速で移動(`progress` 1→0)
- 演奏開始前に 1.2 秒のリードタイムを置く

## テスト方針

- `src/game/` の純粋関数(judge / score / chart / stages / music / progress)を Jest でユニットテスト
- ステージ定義はデータバリデーションとしてテスト(拍位置が小節内、スターが部分集合、など)
- Web Audio 依存の `audio.ts` と React フック・UI はカバレッジ対象外
- カバレッジしきい値: 80%(現状ほぼ100%)
