# リズムFable ゲーム仕様

## 概要

リズム天国風のワンボタンリズムゲーム。BPM 120 のメトロノームに合わせて右から流れてくる音符(🎵)が、キツネ(🦊)のいるヒットゾーンに重なった瞬間に入力する。

- 入力: スペースキー / タップ / クリック
- 1プレイ: 16小節(カウントイン4拍 + 約32秒)

## 画面フロー

```
タイトル → プレイ中 → リザルト
   ↑          　        │
   └──「タイトルへ」──────┤
              ↑「もういちど!」で再プレイ
```

## タイミング判定 (`src/game/judge.ts`)

入力時刻とノーツ時刻の差(絶対値)で判定する。

| 判定 | 表示 | 許容誤差 |
| --- | --- | --- |
| perfect | ピタッ! | ±50ms |
| good | まずまず | ±110ms |
| miss | あちゃー | ±200ms(入力あり) / 通過(入力なし) |

- ±200ms を超える入力はノーツを消費せず無視する(空振りペナルティなし)
- 入力は「最も近い未判定ノーツ」に対して判定される
- ノーツ時刻を 200ms 過ぎても入力がなければ自動的に miss

## スコア (`src/game/score.ts`)

- 基礎点: perfect 100点 / good 50点 / miss 0点
- コンボボーナス: ヒットごとに現在コンボ数を加点(上限50点)
- miss でコンボは0にリセット(maxCombo は保持)

### 評価(リザルト)

精度 = (perfect数 + good数 × 0.5) ÷ 総ノーツ数

| 評価 | 条件 |
| --- | --- |
| ハイレベル! | 精度 85% 以上 |
| まずまず | 精度 60% 以上 |
| やりなおし… | それ未満 |

## 譜面 (`src/game/chart.ts`)

- 譜面は「小節ごとの拍位置の配列」で定義する(例: `[0, 1.5, 2]` = 1拍目・2拍目の8分裏・3拍目)
- `buildBeats()` で通し拍数に展開し、`createChart()` で秒数付きノーツ列に変換
- メインステージ `FABLE_PATTERNS` は16小節。基本パターン → 8分裏 → 16分裏(3.5拍)と徐々に難しくなる

## サウンド (`src/game/audio.ts`)

Web Audio API のオシレーターでリアルタイム合成する(音源ファイルなし)。

- メトロノーム: 全拍で再生。小節頭はアクセント(1オクターブ上・大きめ)
- 判定音: perfect は2音チャイム、good は単音、miss は低いノイズ風
- リザルト: 評価に応じた3〜5音のジングル

タイミングの基準はすべて `AudioContext.currentTime`(オーディオクロック)を使い、描画は `requestAnimationFrame` で追従する。メトロノームは 150ms 先読みしてスケジュールする。

## エンジン (`src/hooks/useGameEngine.ts`)

- ゲーム状態(判定済み配列・スコア・次のメトロノーム拍)は ref に持ち、毎フレーム `GameSnapshot` として React に反映
- ノーツは到達2拍前に出現し、ヒットゾーンまで等速で移動(`progress` 1→0)
- 演奏開始前に 1.2 秒のリードタイムを置く

## テスト方針

- `src/game/` の純粋関数(judge / score / chart)を Jest でユニットテスト
- Web Audio 依存の `audio.ts` と React フック・UI はカバレッジ対象外
- カバレッジしきい値: 80%(現状 100%)
